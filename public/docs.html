AbsChat Docs

Wallet-based messaging on Abstract with onchain delivery, indexed history, regular chats, and shared-password secret chats.

Overview

AbsChat is a messenger for AGW users on Abstract. Messages are sent as zero-value transactions with calldata, then mirrored into indexed storage so chats can load fast, sync across devices, and support modern UI features.

Chat Modes

  • Regular chats: encrypted payloads with backend-managed conversation secrets for new chats. This mode is safer than the old legacy scheme, but it is not E2EE.
  • Secret chats: shared-password E2EE. Both sides must set the same password to decrypt messages.
  • Legacy compatibility: older regular chats can still be read through the legacy fallback so existing history keeps working.

What Syncs

  • Message history and previews
  • Display names and avatars
  • Online status, typing, and seen state
  • Emoji reactions across devices and participants
  • Local pins across the same account's devices
  • Shared pins across both chat participants
  • Secret-chat visibility across the same account's devices

Delivery and Recovery

  • Realtime broadcast handles typing, reactions, pins, read state, and visibility.
  • Indexed history from Supabase keeps chat loading fast on refresh and across devices.
  • Periodic polling and a light chain scanner help recover when realtime misses events.

Security Model

  • Frontend signs a wallet message to obtain a short-lived backend JWT.
  • Indexed reads and writes go through backend API routes.
  • Supabase service-role credentials stay on the backend only.
  • Regular chats are server-trust encryption, not E2EE.
  • Secret chat passwords are stored only on the local device and never synced.
Important: secret chats are the private mode. Regular chats are the default cloud-style mode and should not be described as E2EE.

Sessions

AbsChat can create a local sending session so you do not need a wallet confirmation for every single message. Session data lives on the current device and can be revoked from settings.

What Stays Public

  • Wallet activity and tx hashes on Abstract
  • Onchain timestamps
  • Ciphertext payloads written into transaction calldata

Getting Started

  • Connect AGW.
  • Open or create a chat with another address.
  • Send a message, or create a session for faster sending.
  • Use a secret chat when you want shared-password E2EE.
